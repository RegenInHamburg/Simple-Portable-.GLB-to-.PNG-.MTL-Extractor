Simple Portable .gbl to .obj Converter. With Textures as .png and .mtl files.

Run build_portable_runtime.bat afer extracting with 7zip / winrar
After that enjoy a Night Themed  simple GUI. Input your Model, select Output location. And it converts your .glb Game Asset Model or 3D Print into an .obj and .png texture and .mtl material.
(Try to have the model files you wanna unwrap / convert in the extracted folder (so next to the other files of my zip, top folder)
